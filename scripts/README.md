# scripts/

`note_login_test.js` — Playwright を使って note.com へのログインを試すための検証スクリプト。

**現状（2026-09-05時点）**: このセッションが動くサンドボックス環境のネットワークポリシーが `note.com` へのアウトバウンド接続を拒否（プロキシが403を返す）しており、自動ログイン・自動投稿は実行できない。回避は行っていない。

環境のネットワークポリシーで `note.com` への接続が許可されれば、このスクリプトを土台に自動投稿フローを組める。

認証情報は `.env`（`NOTE_ID` / `NOTE_PASSWORD`）から読み込む想定。`.env` は `.gitignore` 済みで、リポジトリには含めない。
